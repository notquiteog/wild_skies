- Public `mod.game` supplies the live game. The API3 world facade has no `.game` member. GB rendering/ecology retains its native data compatibility view, while live world/viewport reads use the public native game.

## Remaining native extensions / limits

`engine_internals` remains required for per-pixel flyer animation, altitude, native sprite projection and resident neighbor ecology. API3 spawnNpc has no public independent altitude/non-NPC render entity interface. This migration does not claim those native rendering internals became portable services. Optional Doubles flock recruitment requires its new scoped export; without it Skies uses the validated public single battle path.

Native optional integration passes FireRed/Emerald × Ride air/Skies ground × always/off/no-mate (12 cases): only a distinct same-flock bird is consumed, OFF consumes no mate, and no-mate stays single. Raw assets, ROMs, SDK source and captures are not committed.
